# Atividades de Lógica com JavaScript e HTML

Esta pasta reúne exercícios e atividades práticas desenvolvidos com JavaScript e HTML, focados no aprendizado de lógica de programação e desenvolvimento web. Os projetos exploram conceitos essenciais como variáveis, operadores, estruturas condicionais, laços de repetição, funções, manipulação de dados e interação com o usuário por meio de páginas web simples e dinâmicas.
